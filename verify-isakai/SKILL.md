# Verify Isakai runtime

## Build

From the repository root, run `zig build` and `zig build test --summary all`.
Use Zig 0.17 and a JDK 17+ compiler; host system libraries are listed in
[host requirements](../docs/HOST_REQUIREMENTS.md).

## Checks

| Surface | Command | Pass criteria |
|---|---|---|
| Framework regressions | `python3 tools/test-framework.py` | Every discovered Java test program passes in its own JVM. |
| Translation cache | `python3 verify-isakai/check-translation-cache.py` | CLI preserves valid cached classes, regenerates old DEX-only and changed-translator caches, and launches regenerated bytecode. |
| Navigation | `python3 verify-isakai/check-navigation.py` | Mapped Wayland windows show both Unicode titles; explicit activity launch/result, lifecycle observers and main-thread dispatch match assertions. |
| Compatibility diagnostics | `python3 verify-isakai/check-compat-report.py` | Seeded missing API, nested runtime cause, private payload redaction, ARM-only ABI and unsupported opcode produce actionable JSON. |
| APK boundaries | `python3 verify-isakai/check-apk-limits.py` | CLI enforces compressed/expanded limits and host ABI selection. |
| Packaged files | `python3 verify-isakai/check-packaging.py` | Actual staged install includes three action IDs and executable wrappers; legacy policy migration and uninstall preserve unrelated files. |
| Production sandbox, same UID | `python3 verify-isakai/check-runtime.py` | Real JVM and IsakaiMain start; data/stage writes succeed; code/outside writes and other-data reads fail; NNP/seccomp present; ffprobe runs if installed, with the production shim preloaded. Does not prove UID or mount separation. |
| Live window, same UID | `python3 verify-isakai/window-flow.py --unprivileged --required` | Real fixture stays open >30 seconds, accepts text, closes through compositor and back, records exit zero and removes data. |
| Isolated target-app flows | `python3 verify-isakai/sway-flow.py {opencalc|calculator|notes} --work <dir>` | OpenCalc calculates/copies/resizes and stays alive; Calculator reaches settings, persists the decimal preference and returns via back; Notes edits a Unicode note, saves it and returns to the list. Each flow retains screenshots and app logs under `--evidence`. |
| Harness negative | `python3 verify-isakai/check-harness-failure.py` | Deliberate launch exit 42 cannot be hidden by success-shaped lifecycle logs; harness fails and uninstalls fixture. |
| Full privileged flow | `tools/e2e-privileged.sh --required` | Fresh fixture and peer app install; app-side UID/GID, empty groups, NNP, seccomp, distinct mount namespace and filesystem assertions pass; real surface/input/lifetime/close/back pass; users/data removed. |

The live driver currently supports Hyprland (both legacy and Lua dispatchers),
`grim` and `wtype`. Full privileged mode also requires noninteractive `sudo`,
`getfacl` and `setfacl`. No credentials are stored. It grants the temporary app
UID access to the compositor socket using an ACL and restores the original ACL
on exit; it does not make the socket world-writable. Test work uses a unique
`/tmp/isakai-e2e-*` directory, and screenshots/logs are retained there.

Without prerequisites, the privileged script returns 77 with SKIP; `--required`
or `ISAKAI_E2E_REQUIRED=1` turns that into exit 1. CI must use required mode.
Build failures, missing executables, subprocess failures and assertion failures
are errors, never skips. The privileged entry point rejects `--unprivileged`.

The isolated target-app flow requires the private Sway fixture and
`isakai-vinput` built by the repository's compositor fixture. Start that
fixture before invoking `sway-flow.py`; a missing compositor is an environment
failure, not an app-flow pass or skip.

Inspect `opened-*.png` and `typed-*.png` for the fixture text and typed RUNTIME
suffix, and `isolation.log` for app-side results. Record paths and outcomes in
[progress.json](../progress.json), the only progress tracker. A same-UID pass
must not be reported as a privileged pass.

To test a distro JDK explicitly, pass
`--java /usr/lib/jvm/<jdk>/bin/java` to `check-runtime.py`. This catches
configuration symlinks outside JAVA_HOME as well as subprocess thread creation.

## Platform references

- [Linux Landlock UAPI](https://docs.kernel.org/userspace-api/landlock.html): version query, ruleset creation, ABI rights and inheritance.
- [polkit action declarations](https://polkit.pages.freedesktop.org/polkit/polkit.8.html): multiple actions per namespace policy file.
- [Hyprland dispatchers](https://wiki.hypr.land/configuring/core/dispatchers/): version-aware focus and graceful close of the exact test window.
