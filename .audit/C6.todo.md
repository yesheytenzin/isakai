## Playbook steps (verbatim)

1. Reproduce it yourself on the matching surface via the driver skill.
2. Binary-search the cause. Confirm the surviving mechanism with runtime evidence before the fix.
3. Plan the fix. If it crosses a function boundary, architect first. Delegate implementation with a specific scope.
4. Verify on the same surface. The original repro now passes.
5. Stage the commits so the failing repro lands before the fix in git history (tdd cadence when cheap).
6. Run Opening a PR.
