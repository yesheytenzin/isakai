# Testing

Three layers, all runnable on a dev machine. `zig build test` and
`./oracle/diff.sh` must be green before any milestone gate.

## 1. Unit tests: `zig build test`

Runs the `test` blocks of 9 modules: `isakai`, `registry`, `install`,
`dex`, `translate`, `launch`, `apksig`, `uid_helper`, `window`.
(`xkb` is covered indirectly through the window tests' fake backend;
`jni` needs a live JVM, covered by layer 3.)

Notable suites:

- `apksig`: 35 AOSP v2 golden vectors (`@embedFile`, offline) asserting
  exact fingerprints / exact `SigError`s, plus EOCD tests. Refresh via
  `tools/fetch-apksig-vectors.sh` (one-time network use).
- `translate`: opcode lowering unit tests (wide fixups, component
  tracking, rejection rules).
- `window`: Wayland wire codec vectors + synthetic configure/seat
  payloads driving the ring/resize logic without a compositor.
- `registry`/`install`/`launch`: state machine, validators, argv shape,
  uninstall-abort paths.

## 2. Differential oracle: `./oracle/diff.sh [case...]`

Each case: smali corpus → `d2j-smali` DEX → our `translate-test` vs
`dex2jar` → compile the `<Case>Driver.java` against both → run both on
the host JVM → diff stdout. Cases auto-discover from `oracle/corpus/`.

Prereqs (one-time): dex-tools v2.4 unpacked at `$D2J` (default
`/tmp/oracle/dex2jar/dex-tools-v2.4`):

```sh
mkdir -p /tmp/oracle/dex2jar && cd /tmp/oracle/dex2jar
curl -L -o d2j.zip \
  https://github.com/pxb1988/dex2jar/releases/download/v2.4/dex-tools-v2.4.zip
unzip -o d2j.zip   # provides d2j-smali.sh, d2j-dex2jar.sh, baksmali
```

Plus a host JDK (`javac`/`java`, 17+) for drivers and `javap`.

Suites (16): `arith`, `arrays`, `switch`, `sync`, `trycatch`, `wide`,
`cmp`, `filledarray`, `consts`, `lines`, `constclass`, `moves`,
`widefill`, `widedouble`, `jumbostr`, `goto32`. `jumbostr.smali` is
generated by `oracle/corpus/jumbogen.py` (300-string pool). `lines.sh`
runs last and adds 2 checks (`dump-lines` vs `javap -l -c` vs baksmali
`.line`), for 18 assertions total.

## 3. Live gates (compositor + fixture)

```sh
zig-out/bin/fixture-apk /tmp/fixture.apk
export ISAKAI_NO_PRIVILEGE=1 ISAKAI_ALLOW_UNSIGNED=1
export ISAKAI_FRAMEWORK=$PWD/zig-out/framework
zig-out/bin/isakai install /tmp/fixture.apk
zig-out/bin/isakai launch org.isakai.fixture                      # headless
ISAKAI_WINDOW=1 zig-out/bin/isakai launch org.isakai.fixture      # windowed
```

- Headless: counter lifecycle logs, exit 0 (M1).
- Windowed: xdg_toplevel appears (`hyprctl clients`), grim screenshot
  shows the rendered UI, exit 0, no leftover windows (M2).
- Input: `wtype` types into the focused EditText; `ydotool click 0xC0`
  (full LEFT click; bare `click 0` is a no-op mask, coordinates are
  relative by default) clicks the Button; log shows the click handler
  (M3). `ydotoold` must be running with uinput access.

Real-APK ladder (translator scale): `verify-test <apk>` for signature,
`translate-test --keep-going <classes.dex> <out>` for per-class
translation survey. KeePassDroid v2.6.9.2: 11953/11953 translate,
0 VerifyError (see fix-plan Phase 3).
