# D2: Enforce artifact policy and remove obsolete project files

## Dependencies

None.

## Code and documentation

- [AGENTS.md](../AGENTS.md)
- [Verification skill](../verify-isakai/SKILL.md)

## Implementation

1. Make the verification skill's artifact policy apply to every project task.
2. Prohibit creating test cases/files and permit new scripts only when an
   existing command or implementation cannot fulfill a concrete requirement.
3. Audit callers before removing obsolete probes, stray app preferences,
   unused toolchain artifacts and generated build/Python caches.
4. Preserve source, packaging, licenses, task history, required tooling,
   pinned APKs, recorded evidence and needed app work directories.

## Acceptance

- One canonical skill policy governs test/script creation, including work
  performed with other skills.
- No active build target, import or document link refers to a removed source.
- Existing necessary tooling and a normal build still work after cleanup.
- Review and cleanup results are recorded here before changing status to done.

## Verification evidence

### 2026-10-14 — passed

Added project instructions routing every task/skill to the canonical
verification-artifact policy. The policy prohibits new test cases, test files,
test-only code and temporary regression harnesses. New scripts/helpers require
a concrete necessity that existing commands or code cannot fulfill, documented
in the task. Updated live plan entries to use existing Android applications
and artifacts instead of authoring new fixtures.

Removed ten obsolete tracked files:

- `tools/findA.zig`, `tools/findM.zig`, `tools/runtime-probe.zig` and their
  build targets. The first was hardcoded to an obfuscated app method; none
  had an active caller beyond the build definition.
- `verify-isakai/sway_backend/ordered_test.py`, `probe_calc.py`,
  `probe_calc_menu.py` and `probe_equals.py`, superseded by the existing
  application-flow drivers. The ordered probe also had a stale import path.
- Three generated preference XML files under the root-level OpenCalc,
  Calculator and Notes package directories, followed by their empty folders.

Removed the unused dex-tools ZIP branch, cache discovery, D2J environment
export and unused imports from the existing bootstrap tool. Added root-only
ignore rules for generated app data and packaging staging.

Unused dex-tools caches, generated `zig-out`/`.zig-cache` directories and
three Python bytecode-cache directories were moved out of the project to
`/tmp/isakai-cleanup.EYoFnc` (681 MiB). Bulk deletion was rejected by the
cleanup guard; recoverable relocation provided a safer root cleanup.
These generated outputs can be recreated by normal build commands.
Pinned APKs, recorded evidence, active app work trees, the compositor fixture
and the pinned Zig/JDK toolchain remain available because they are still used.

The normal build passed after target removal. Existing APK inspection and
signature CLI commands read the pinned OpenCalc APK successfully and reported
the expected package and signer fingerprint. Bootstrap verified both cached
toolchain hashes, the fetch CLI verified all three pinned APK hashes, the
existing Sway CLI help loaded, skill validation passed, and Zig formatting
and git diff checks passed. Reference searches found no active caller of the
removed sources. No new test cases, test files or scripts were created.

Commands used:

```sh
zig build
zig-out/bin/inspect-test .cache/isakai/apks/OpenCalc.v3.2.1.apk
zig-out/bin/verify-test .cache/isakai/apks/OpenCalc.v3.2.1.apk
PYTHONDONTWRITEBYTECODE=1 python3 tools/bootstrap.py zig jdk
PYTHONDONTWRITEBYTECODE=1 python3 tools/fetch-apps.py
PYTHONDONTWRITEBYTECODE=1 python3 verify-isakai/sway-flow.py --help
zig fmt --check build.zig
git diff --check
```

Build outputs were relocated after verification. This cleanup does not claim
new application acceptance or resolve the privileged-harness blocker in N1.
