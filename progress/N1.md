## Implementation

1. Provide tracked, pinned compositor/vinput build or distro setup with configurable runtime root instead of a hardcoded /tmp instance.
2. Create and tear down a private session per run; verify Wayland and IPC sockets before launch.
3. Record revision, dirty diff hash, toolchain, host ISA/page size, APK hash, selected ABI/backend, actions, screenshots and exit status in immutable run directories.
4. Preserve UI-only verification policy; add an explicitly provisioned privileged release runner rather than claiming build-only CI proves app behavior.
5. Remove the privileged harness dependency on deleted RuntimeProbe.java using existing runtime/application diagnostics and observable isolation state; do not author a replacement test case or fixture file. Keep any acceptance that cannot be observed explicitly blocked.
6. Make OpenCalc result/copy assertions refer to the current expression and newly committed result, never stale history; reject visible Syntax regardless of historical values.
7. Extend Notes flow with visible list/back assertion, process close/restart, note reopen and exact Unicode-content verification.
8. Retain the failing opencalc10 data/settings and passing clean opencalc-fresh input separately; compare persistence/history and require retained-state restart/upgrade behavior before claiming reliability.

## Acceptance

- A fresh checkout can set up and complete the recorded OpenCalc private-Sway flow without an untracked cached binary.
- Missing prerequisites or app errors fail the required run, preserve evidence and clean up processes/sockets.
- Privileged release results remain distinct from development same-UID results.

## Stop condition

Do not publish current-architecture or default-isolation acceptance if the run depends on the maintainer's temporary compositor or bypasses privilege.
